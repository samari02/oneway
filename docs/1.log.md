### #34 Empathetic AI coach with context & memory

**Date:** 2026-01-10

- **Prompt empathique réécrit** :
  - Personnalité chaleureuse, patiente, genuinement curieuse
  - Valide les émotions avant de conseiller
  - Pose des questions profondes sur le "pourquoi"
  - Utilise le prénom de l'utilisateur
  - Répond dans la langue de l'utilisateur

- **Approche structurée** :
  - D'abord comprendre la motivation profonde
  - Identifier les obstacles actuels
  - Visualiser le succès
  - Seulement après → suggérer des actions

- **Contexte utilisateur passé à l'AI** :
  - `displayName` — prénom pour personnalisation
  - `currentGoal` — objectif actuel
  - `habits` — liste des habitudes existantes
  - `wakeTime` / `sleepTime` — horaires de vie
  - `previousConversations` — résumé des échanges passés

- **Mémoire persistante** (`009_ai_conversations.sql`) :
  - Nouvelle table `ai_conversations` dans Supabase
  - Stocke messages + contexte par utilisateur
  - Fonctions `saveConversation`, `loadConversation`, `clearConversation`
  - `getPreviousConversationsSummary` pour inclure l'historique
  - RLS pour sécurité des données

- **Intégration modal** :
  - `NorthStarEditModal` reçoit `userSettings` en props
  - Contexte construit dynamiquement à chaque message
  - Conversations sauvegardées automatiquement
