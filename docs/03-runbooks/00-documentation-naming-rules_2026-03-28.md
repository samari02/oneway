# Documentation Naming Rules

**Last update:** 2026-03-28

---

## File Naming Format

All documentation files in this folder should follow:

```
name1_name2_YYYY-MM-DD.md
```

- **name1_name2**: Descriptive snake_case name (e.g. `deployment_checklist`, `common_errors`)
- **YYYY-MM-DD**: Date of last update (e.g. `2026-03-28`)

### Examples

- `vercel_build_2026-03-28.md`
- `20251023_observers_deployment_checklist.md` (date prefix variant)
- `secrets_management_2026-03-28.md`

---

## Required Header

Each markdown file must include the date of last update at the beginning:

```markdown
# Document Title

**Last update:** YYYY-MM-DD

---
```

---

## When to Update the Date

Update the date in both the filename and the header when you make substantive changes to the document.
